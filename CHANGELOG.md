# Changelog

## 0.1.0
- First public version: resonant band-pass wah (position, Q/peak, range, level), bypass, fixed / MIDI-pedal mode, vintage / modern voicing.
- Skeuomorphic rack panel with real-time lit knobs, LCD, previous/next preset keys, 18 factory presets and user presets.
- VST3 for Linux, Windows and macOS (universal).
